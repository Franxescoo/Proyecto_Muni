¿Necesitas orientación?
Guía rápida de Organización
{% if active_page == 'employees' %}

Consulta los datos de cada empleado y su cuenta integrada. Los roles se heredan del cargo.

  1. Busca por nombre, RUT, cargo o delegación.
  2. Usa Ver para consultar y Modificar para editar, según tus permisos.
  3. En Historial revisa las acciones realizadas por la persona y los cambios recibidos en su ficha.
  4. Al guardar, comprueba el resultado antes de salir.
{% elif active_page == 'delegations' %}

Administra las unidades territoriales municipales y sus responsables.

  1. Filtra delegaciones por nombre, código, comuna o estado.
  2. Usa Nueva delegación cuando tengas permiso para crear.
  3. Consulta o modifica la delegación desde su tarjeta.
  4. Antes de desactivar una delegación, revisa sus vinculaciones.
{% elif active_page == 'positions' %}

Los cargos definen funciones, vigencia y roles que se heredan a las cuentas de empleados vinculados.

  1. Busca cargos por nombre, servicio o ítem.
  2. Filtra por vigencia para consultar cargos actuales o históricos.
  3. Usa Nuevo cargo si tienes permiso.
  4. Al modificar los roles de un cargo, revisa las consecuencias para los empleados asociados.
{% elif active_page == 'roles' %}

Los roles reúnen permisos; solo puedes realizar las operaciones autorizadas para tu cuenta.

  1. Busca un rol por nombre o descripción.
  2. Usa Crear rol si cuentas con el permiso correspondiente.
  3. Revisa cuidadosamente los permisos antes de guardar.
  4. Los cambios autorizados quedan asociados al historial de actividad del usuario que los realizó.
{% else %}

Usa los filtros, revisa los registros y realiza únicamente las acciones habilitadas por tus permisos.

{% endif %} La guía no modifica información ni concede permisos.
