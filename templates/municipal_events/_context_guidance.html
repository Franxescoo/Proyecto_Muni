{% if section == 'events' %}

Registra un evento municipal y administra sus ediciones por año. Desde cada evento puedes consultar las ediciones existentes y registrar una nueva cuando corresponda.

Antes de agregar una edición: primero debe existir el evento municipal. La edición identifica el año, fecha, lugar, delegación y responsable de esa realización.

{% elif section == 'campaigns' %}

Crea campañas, define sus fechas de inscripción y consulta su estado. Puedes vincular una campaña con una edición de evento, pero esa vinculación es opcional.

Para crear una campaña: necesita un tipo de atención activo del catálogo. Para recibir inscripciones, debe estar en estado «Inscripciones abiertas» y encontrarse dentro de sus fechas de apertura y cierre.

{% elif section == 'enrollments' %}

Aquí puedes consultar las inscripciones registradas y evaluar las pendientes, indicando una decisión y su motivo. Las inscripciones no se crean directamente desde este listado.

Para inscribir a un beneficiario: debe existir una atención del tipo vinculado a una campaña abierta. Ve a Registro y Validación → Ingreso de Atención y utiliza «Inscribir en campaña». El sistema comprueba los duplicados a nivel municipal.

{% elif section == 'deliveries' %}

Consulta los beneficiarios aprobados, distingue entregas pendientes de las realizadas y registra la constancia al efectuar una entrega.

Para registrar una entrega: la inscripción debe estar aprobada y no tener una entrega anterior. Se registra la fecha y el funcionario responsable, según los permisos disponibles.

{% elif section == 'history' %}

Revisa los movimientos de una campaña o beneficiario para seguir el proceso de inscripción, evaluación y entrega. Este historial se genera desde las operaciones realizadas; no necesitas registrar los movimientos manualmente.

{% endif %}
{% endif %}
