Guía rápida · Ingreso de atenciones

{% if perms.registration_validation.add_attentionentry %}

{% endif %} {% if perms.registration_validation.change_attentionentry %}

Guía rápida · Actividades

Busca por solicitud o problema, acción, funcionario o meta, y utiliza el filtro de estado para acotar los resultados. Consulta los detalles desde las acciones de la fila.

{% if perms.registration_validation.add_activity %}

Para registrar una actividad, asóciala a una meta y a una atención existente. Completa la solicitud o problema, la acción realizada, el funcionario y los demás datos requeridos; las actividades nuevas también requieren un tipo activo.

{% endif %} {% if perms.registration_validation.change_activity %}

Al modificar una actividad, revisa el estado y conserva la relación con una atención de la misma delegación del funcionario autor. No se pueden modificar actividades de períodos cerrados o archivados.

{% endif %} {% elif help_section == "evidence_list" or help_section == "evidence_create" or help_section == "evidence_update" %}
Guía rápida · Evidencias

Busca por código, actividad, meta o funcionario, y filtra por estado de revisión. Desde la lista puedes consultar los respaldos disponibles; los archivos privados mantienen sus controles de acceso.

{% if perms.registration_validation.add_evidence %}

Para registrar una evidencia, selecciona una actividad y un funcionario. El código se genera automáticamente. Adjunta entre 2 y 5 archivos permitidos, con un peso total máximo de 50 MB; también puedes añadir un enlace como dato adicional.

{% endif %} {% if perms.registration_validation.change_evidence %}

Al modificar una evidencia, revisa los archivos existentes antes de quitarlos. Después de los cambios deben permanecer entre 2 y 5 archivos y el peso total no debe superar 50 MB.

{% endif %}

Para consultar la decisión y el resultado de una revisión, abre Validaciones.

{% elif help_section == "validation_list" or help_section == "validation_create" or help_section == "validation_update" %}
Guía rápida · Validaciones

{% if perms.registration_validation.add_validation %}

{% endif %} {% if perms.registration_validation.change_validation %}
